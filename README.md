# 小剧组 · Little Crew

**当前版本 `0.4.0-alpha.69`** · Apache-2.0 · Python 3.12+

> 基于多智能体协作的 **AIGC 漫剧生成平台**
>
> 以 ComfyUI 节点化架构与 API 为执行底座，自研统一中间表示（Unified IR）与
> Transformer 调度智能体的可视化编排与服务平台。

> **当前状态**：核心 10 层已实现，**已具备端到端出片能力与对外接口** ——
> 跑通过一集 20 镜、120 秒的可播放成片，并有缓存提速（1889×）、
> 断点续跑、白模空间控制、验收门禁（拦截率 100% / 误杀率 0%）的实测数据；
> CLI 与 HTTP 接口均可用。
> **尚未实现**：自研 Transformer 三模块（**C2，三个创新点里唯一没落地的**）、
> 角色锚点图与参考图注入（图像层一致性）。
> 详见策划书 **§5.10「未完成清单」**。
> 详见 [`CHANGELOG.md`](CHANGELOG.md) 的「已知限制」。

## 这个项目要解决什么

AIGC 漫剧（动画短剧）生产有四个结构性困难：

| # | 困难 | 本质 |
|---|---|---|
| **P1** | 长程一致性崩塌 | 一集 60–120 镜，角色脸/服装/场景跨镜漂移；扩散模型无跨镜记忆 |
| **P2** | **编排粒度错配** | 创意决策是**语义级**的，扩散执行是**张量级**的，两者之间没有共享表示 |
| **P3** | 验收自证 | 出图的模型自己说"这张没问题"，错误逐帧累积无人拦截 |
| **P4** | 成本与重跑失控 | 单集数百次 GPU 生成，改一个参数导致全量重跑；中断即从头 |

**核心创新**：**双层同构 DAG + 统一 IR**，让语义约束与扩散执行共享同一份
可编译、可校验、可回溯的图结构——同时解决 P2、并为 P1/P3/P4 提供落地基础。

```
语义图（角色/镜头/连续性）  ←→  统一 IR  ←→  ComfyUI 节点图
```

## 快速上手

```powershell
# 1. 探测环境（两个通道是否可用、关键节点是否在位）
python -m little_crew.cli probe

# 2. 跑单镜（最小可复现单元）
python -m little_crew.cli shot "一位穿米色风衣的少女走在白天的山间小路上"

# 3. 跑一集（不带 --script 时用内置样例剧本，可直接成功）
python -m little_crew.cli episode --limit 2

# 4. 起 HTTP 服务（默认绑 127.0.0.1 —— 本服务无鉴权，勿轻易改）
python -m little_crew.api
```

**退出码是分类的**：`0` 成功 / `1` 业务失败 / `2` **环境不可用** / `3` 用法错误。
`1` 与 `2` 的区别让 CI 能分流"该修代码"与"该去装东西"。

所有命令支持 `--json`，输出可直接被 `jq` 消费。

### ⚠️ 一处要如实说明的能力边界

`review` 层的 **L2 一致性描述子**能抓配色/光照/构图漂移（受控退化实验
**归因 12/12 正确**），但**测的不是身份**：同一角色在不同构图下的分数
（0.66）与不同场景的分数**区间重叠**，没有阈值能把两者分开。

所以它只做 **`audit`**（如实记录、不阻断）。

**把能力缺失伪装成"发现了缺陷"，比不做度量更糟** —— 详见策划书 §5.9.3。

## 本机硬件约束（已实测，影响所有设计取舍）

| 项目 | 值 | 影响 |
|---|---|---|
| GPU | RTX 4060 Laptop **8 GB** | 同时只能加载一个模型 → **GPU 必须按模型分批调度** |
| **内存** | **15.8 GB** | ⚠️ **真正瓶颈**：无法训练角色 LoRA → **一致性必须参考图优先** |
| H3 视频时长 | **上限 10 秒**（12s 必 OOM，降分辨率无效） | 单镜时长上限 10s，>10s 自动拆段 |
| 单集 GPU 时间 | **4~7.5 小时**（60 镜） | 缓存/检查点/两阶段草稿是**生死线**，不是优化项 |
| 单集现金成本 | **≈ ¥5** | 瓶颈是时间不是钱 |

详见 [`docs/02-模型调研与适配方案.md`](docs/02-模型调研与适配方案.md) 第 1 章与第 3 章。
