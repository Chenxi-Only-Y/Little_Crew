# `research/cast-consistency/` —— 新算子的**真实发生率**（以及一次自我修正）

**日期** 2026-10-17~18 · **版本** `0.4.0-alpha.49` · **脚本** `measure_incidence.py`

---

## 一句话结论

**`cast_consistent_with_text` 在真实 LLM 内容上的发生率是 0%（0/163 镜）。**

它是为**桩路径的缺陷**写的，不是为生产写的。**不升 `hard`** —— 但不是因为拦得太多，
而是因为**它在真实内容上什么都不拦**。

**上一轮"它抓到了真缺陷"这个说法需要修正**（见 §4）。

## 一、怎么量的

**关键点：这条断言只看镜头元数据（`characters` + `description`），
而它们由分镜阶段产出 —— 所以测量可以完全跳过出图。**

| | 出图版 | **本测量** |
|---|---|---|
| 单集耗时 | ~19 分钟 | **~7 分钟** |
| 单集成本 | 24 次渲染 | 0 次渲染 |
| 量到的东西 | 与门禁同一算子、同一份输入 | **同上** |

> `_inputs_for()` 刻意复制 `episode.py::_run_gate` 里 `context` 的构造。
> 若两者不一致，测到的就不是门禁里跑的那件事。

**样本**：3 份**不同题材**素材 × 各 2 次 = 6 集。

| 素材 | 为什么选它 |
|---|---|
| 薰衣草 | 抒情长镜多（原文案） |
| 都市悬疑 | 室内短场多、人物关系紧 |
| 山野奇谭 | 单人独处场景多 ← **最可能触发"独自"类矛盾** |

## 三、为什么是 0% —— 与桩路径对比

| 路径 | 发生率 | 原因 |
|---|---|---|
| **桩**（`crew_stubs`） | **50%（1/2）** | 分镜把**整场角色**塞给每一镜 → "独自"那镜也带 2 人 |
| **真实 LLM** | **0%（0/163）** | 分镜**逐镜分配**：106 镜 1 人 / 57 镜 2 人，描述都对得上 |

真实描述长这样：

```
[1人] 全景。天刚亮的薰衣草田…阿薰蹲在田垄间，手指掐断花茎…
[2人] 中全景。集市布摊上…阿薰站在摊后。买菜妇人挑了一束，皱眉丢下两枚硬币转身走。
```

**LLM 分镜师是按"这一镜画面里有谁"来填 `characters` 的**，所以文本与结构天然自洽。
桩是机械切分的，才会出现"整场卡司塞每镜"。

## 四、⚠️ 一次自我修正

上一轮（`alpha.48`）我写的是：

> "它抓到了真缺陷"、"演示素材 2 镜命中 1 镜（50%），先别升 hard"

**这个说法需要修正：**

| 我说过 | 实际 |
|---|---|
| 抓到了真缺陷 | 抓到的是**桩路径的缺陷**，不是生产的 |
| 50% 命中 → 不敢升 hard | 50% 是**夹具的属性**；真实内容 **0%** |
| 这条断言解决"画面多出人" | **解决不了** —— 见下 |

**教训**：**一个在夹具上命中的断言，不等于它在生产上会命中。**
夹具是我们自己造的数据，它反映的是**我们的构造方式**，不是模型的行为。
—— 这和 `alpha.46` 那次"`if r["bestScore"]` 把 0.0 当假值"是同一类错误：
**从局部数据推出全局结论。**

## 五、真正的问题**仍然开着**

24 镜那次的真实缺陷是：

```
characters = ["少女"]   →   画面里画了 2 个人
```

**角色表 1 人、描述也完全自洽** —— 文本层没有任何矛盾。
**是模型自己多画了一个人。**

| 层 | 能查吗 |
|---|---|
| 文本层（本算子） | ❌ **查不到** —— 输入本身是自洽的 |
| 图像层（L3 视觉判读） | ✅ 能查，但本机需要视觉模型 |

所以这条断言**不解决那个问题**。它在生产上的价值是另一个：
**防止我们自己把桥接/分镜接错**（比如哪天把整场卡司塞进每镜，它会立刻报）。

---

## 六、决定：**保持 `audit`，不升 `hard`**

| 理由 | |
|---|---|
| 在真实内容上**命中 0%** | 升 `hard` 是**空操作**，却会让人以为"多了一层保护" |
| 在桩路径上**命中 50%** | 它实际是**夹具一致性检查**，价值在于防我们自己的回归 |
| `audit` 已经足够 | 它照样记录、照样进报告，成本为零 |

**升 `hard` 的正确时机**：当它开始在真实内容上稳定命中时 ——
而那意味着**分镜的提示词或桥接逻辑变了**，那时它拦下的是真问题。
