# `research/video-mode/` —— **两段式**视频模式的 V1 验收

**日期** 2026-10-18 · **版本** `0.4.0-alpha.67`

---

## 一句话结论

**已有静帧 → 动画化 → 带音轨的 mp4，两镜全成，两段式成立。**

---

## 一、验的是什么

`alpha.66` 只验了**接线**（假通道）。这一步验**两段式真的成立**，
而且走的是**主流程那个方法**（`EpisodeRunner.render_video_stage`，
也就是将来 `run()` 会调的那一个），不是直连探针。

```
已有静帧（Z-Image 产出）  →  render_video_stage  →  mp4（含音轨）
```

## 二、结果

| 镜头 | 体积 | 容器 | 视频轨 | 音轨 | 断言 |
|---|---|---|---|---|---|
| `S01-001.mp4` | 7.86 MB | mp4 | ✓ | ✓ | ✅ |
| `S02-001.mp4` | 5.30 MB | mp4 | ✓ | ✓ | ✅ |

```
ok = True   耗时 662.2s   2 个片段 / 0 失败
```

**662.2s / 2 镜 = 331s/镜** —— 与 `alpha.65` 估算的 ~340s/镜吻合。

## 三、由此确认的成本

| 规模 | 耗时 |
|---|---|
| 2 镜（本次） | **11 分钟** |
| 24 镜（整集） | **≈ 2.2~2.3 小时** |

> `alpha.65` 的推算成立。所以整集 `video_mode` **必须排期跑，不能随手试**。
