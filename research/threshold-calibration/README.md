# `research/threshold-calibration/` —— 通过阈值的实测标定

**日期** 2026-10-17 · **版本** `0.4.0-alpha.41` · **样本** N = 10 · **脚本** `measure_threshold.py`

---

## 一句话结论

**阈值从 80 降到 65**，并且**未通过时改为交出"最好那一轮"而不是"最后一轮"**。

依据：**返工多数在让分数变差**（5/9），而"取最好一轮"让均值 +7 分、波动降 40%。

---

## 一、怎么测的

同一份素材（薰衣草传说）、同一套配置（编剧 DeepSeek / 剧评人 MiMo，跨族）、
同一上限（每集 3 轮），**跑 10 次**，逐轮记录：

- 权威总分（0~100）
- 裁定（PASS / REVISE / ESCALATE）
- 阻断级 / advisory 意见数
- 命中的场次数（完整性公式的分子）
- 每次调用的 token

原始数据 `raw.json`，汇总 `summary.json`。

---

## 二、结果

### 2.1 收敛率

| 阈值 | 收敛率 |
|---|---|
| **80（旧）** | **3/10 = 30%** |
| **65（新）** | **6/10 = 60%** |

轮数分布：`{1 轮: 1, 2 轮: 2, 3 轮: 7}`

### 2.2 ⚠️ 关键发现一：**返工多数在让质量变差**

| 结果 | 次数 |
|---|---|
| ↑ 变好 | **3** |
| ↓ **变差** | **5** |
| = 没动 | 1 |

逐次轨迹（首轮 → 末轮）：

```
# 1   46.2 -> 46.2   ( 0.0)   没动
# 2   80.2            (1 轮)  通过
# 3   55.6 -> 54.4   (-1.2)   变差
# 4   62.8 -> 57.6   (-5.1)   变差
# 5   70.8 -> 62.6   (-8.2)   变差
# 6   55.6 -> 80.2   (+24.6)  变好
# 7   67.9 -> 54.4   (-13.5)  变差  ← 降了 13.5 分
# 8   42.6 -> 62.6   (+20.0)  变好
# 9   63.8 -> 54.4   (-9.4)   变差
# 10  69.6 -> 81.6   (+12.0)  变好
```

**这意味着旧行为"取末轮"经常交出去的是几次里最差的一份。**

### 2.3 关键发现二：**取最好一轮是严格更优的策略**

| 指标 | 取末轮（旧） | **取最好一轮（新）** |
|---|---|---|
| 均值 | 63.4 | **70.3** |
| σ（波动） | 12.8 | **7.7**（降 40%） |
| p25 | 54.4 | 63.8 |
| p50 | 57.6 | **67.9** |
| p75 | 80.2 | 80.2 |
| 范围 | [46.2, 81.6] | **[62.6, 81.6]** |

**不增加任何成本** —— 只是从已有的几轮里挑分数最高的那一份。

### 2.4 阈值怎么选

按"取最好一轮"的分布：

| 阈值 | 通过率 |
|---|---|
| 55 / 60 | 100% |
| **65** | **60%** ← 选它 |
| 70 | 40% |
| 75 / 80 | 30% |

**为什么选 65**：让约六成的运行自动通过、四成升级人工。
那两个数字是**工作量分配**，不是质量指标 ——
想让更多集自动通过就往下调，想更严就往上调。

## 三、⚠️ 这个结果**不能**被读成什么

| 不能读成 | 为什么 |
|---|---|
| 「分数可信、可复现」 | ❌ **分数不可复现** —— 问题列表由 LLM 生成，每次不同 |
| 「65 是正确阈值」 | ❌ 它是一条**可调政策线**，换题材/模型/提示词都会变 |
| 「65 分 = 合格剧本」 | ❌ 完整性是**比例**，所以"2 场缺 1 场"= 76.9 分仍过 65 线 —— **短剧本对这个比例很敏感** |
| 「返工无效，该删掉」 | ❌ 它**3 次里有效**，且是发现真缺陷的唯一途径；问题在于**不该假设它单调改进** |

## 五、这次标定改变了什么

| 改动 | 位置 |
|---|---|
| `PASS_THRESHOLD` 80 → **65**（附完整依据） | `agent/orchestrator.py` |
| 新增 `CycleResult.best` —— 未通过时给"最好那一轮" | 同上 |

## 六、下一步该做什么

1. **样本量**：10 个样本估 p50，置信区间很宽。要更准需 30+ 次（约 ¥1 级成本，时间 1 小时）。
2. **换题材验证**：本标定只用一份素材。换一个故事重跑，看分布是否稳定 ——
   **如果题材间差异很大，"一个全局阈值"本身就是错的设计**，应按题材分组。
3. **short-script 敏感性**：完整性是比例，短剧本（2~3 场）对单个缺陷极其敏感。
   考虑改成"比例 + 最少缺陷绝对数"的组合，而不是纯比例。
