# `research/lighting-effect/` —— 灯光方案**到底改没改画面**

**日期** 2026-10-18 · **版本** `0.4.0-alpha.61`

---

## 一句话结论

**改了，而且是逐字执行的。**

同一镜描述、同一 seed、同一分辨率 —— **唯一差别是提示词里有没有灯光块**。
产出的两张图不是"风格略有不同"，是**白天 vs 夜晚、平光 vs 硬光斜切**。

---

## 一、为什么要量，不能看着像

前三轮（`alpha.57`~`60`）验的都是"**接线对不对**"：
plan 有没有传过去、顺序对不对、产物键对不对。

**那是机制，不是效果。**

一个"接线全对但画面没变"的结果完全可能 —— 提示词里加了灯光描述，
而模型忽略了它。**这种情况下所有测试都是绿的，而功能是空的。**

---

## 二、实验设计

**只改一个变量。**

| 组 | 提示词 |
|---|---|
| A（对照） | 镜头描述 + 风格（55 字） |
| B（有灯光） | 镜头描述 + 风格 + **灯光块**（106 字） |

```
镜头：中景。少女站在薰衣草田边，穿浅蓝粗布连衣裙，背着一只竹篮，
      抬头望向远处，神情有些不安。
灯光：夜；窗在左侧，硬光斜切；冷白；影调 高；
      只照亮她的手与竹篮，其余沉在暗里。主色板：靛蓝、灰白。
seed：4242　　分辨率：640×384　　步数：8
```

## 三、像素统计（代理指标）

| 指标 | A 对照 | B 有灯光 | 变化 | 期望方向 |
|---|---|---|---|---|
| 平均亮度 | 94.65 | **75.39** | ↓ 19.26 | 「夜」应更暗 ✅ |
| 对比（std） | 38.87 | **58.09** | ↑ 19.22 | 「高对比」应更硬 ✅ |
| 色温 R−B | −29.21 | −23.41 | ↑ 5.80 | 「冷白」应更冷 ❌ |

**2/3 方向正确。**

## 四、⚠️ 那个"失败"的指标是**代理指标失效**，不是灯光失效

看图就很清楚：

| 灯光方案要求 | B 图实际 |
|---|---|
| 夜 | ✅ 夜晚深蓝场景 |
| **窗在左侧，硬光斜切** | ✅ **左边真有一扇窗，硬光斜切进来** |
| **只照亮她的手与竹篮** | ✅ 手和竹篮被照亮，其余沉在暗处 |
| 高对比 | ✅ 明暗分界极硬 |
| 冷白 | ✅ 那束光就是冷白色 |

**它不是"稍微变了点"，是照着方案画的。**

`warmBias` 为什么说反了：B 图里**那扇窗的暖光把 R 通道拉高了**，
而整体画面明显偏蓝。**平均值掩盖了空间分布** —— 这是任何
"整图均值"类代理指标的固有问题。

> **教训：代理指标能告诉你"变了没有"，不能告诉你"变得对不对"。**
> 这次它连"往哪个方向变"都说错了。
> **所以本实验同时落盘原图，人眼必须复核。**

## 五、这个结果对论文意味着什么

| 论点 | 证据 |
|---|---|
| **上游职位能影响下游产物** | 灯光方案的文字 → **画面里出现对应的窗与硬光** |
| 多智能体不是"换个提示词" | 灯光师是**独立职位**，产出结构化方案，被**分镜消费**、**渲染兑现** |
| 可量化 | 亮度 −19.26 / 对比 +19.22（同 seed A/B） |

**这是"导演定预算 → 灯光定影调 → 分镜切镜 → 渲染兑现"这条链的
第一个端到端效果证据** —— 前面只有机制证据。

| 局限 | 说明 |

# 八、第二轮 A/B：**用 `gaffer` 真跑产出的方案**

上一轮的灯光块是**我手写的**，而且是为那一镜量身定做的。
所以它只证明了「**文字能改画面**」，没证明「**模型写的文字也能改画面**」。

**这两件事不是一回事**：`gaffer` 是看着整部剧本给每场定光的，
它可能给出通用的、与具体镜头无关的描述 —— 那种描述能不能落进画面，是另一个问题。

## 结果：能，而且是逐字执行

`gaffer` 真跑（2.2 秒）给出的 S01 灯光：

```
夜；唯一的窗在画面左后方，雨夜街灯透过湿玻璃形成一片冷色漫射光，
斜落在桌面与信纸上；室内无其他光源，右侧墙角沉入暗部；冷白；影调 高；
让整间屋子只剩信纸那一小块被照亮，压住少女的犹豫与整夜的疲惫，
暗部吞掉房间其余部分
```

画面（`gaffer_b_with_lighting.png`）里：

| 方案要求 | 实际 |
|---|---|
| 夜 | ✅ 夜晚 |
| **唯一的窗在画面左后方** | ✅ 左后方一扇窗 |
| **雨夜街灯透过湿玻璃** | ✅ **玻璃上有雨痕，窗外真有一盏街灯** |
| **只剩信纸那一小块被照亮** | ✅✅ **信纸是画面最亮的东西，暗部吞掉房间** |

**188 字的灯光描述被几乎逐项兑现。**

## 像素统计

| 指标 | A 对照 | B 有灯光 | 变化 |
|---|---|---|---|
| 平均亮度 | 91.35 | **54.27** | ↓ 37.08（「夜」✅） |
| 对比（std） | 51.60 | 38.70 | ↓ 12.90（「高」❌） |
| 色温 R−B | −3.25 | **−14.21** | ↓ 10.96（「冷白」✅） |

**2/3 方向正确**，而且**比手写版的改动更强烈**（亮度 −37 vs −19）。

## ⚠️ 「对比降了」又是代理指标失效 —— 而且两次都栽在同一类坑上

整幅画面**大部分是暗的**，只有信纸一小块亮 —— **全局 std 必然下降**，
但**感知上的明暗对比很强**。

这与第一轮的 `warmBias` 是同一个病根：**整图平均掩盖了空间分布**。

| 轮次 | 说反的指标 | 病根 |
|---|---|---|
| 第一轮 | `warmBias`（说变暖，实际更蓝） | 窗的暖光拉高 R，整体却是冷调 |
| 第二轮 | `contrastStd`（说对比降，实际很硬） | 画面大部分是暗部，std 被压低 |

> **两次都不是"模型没照做"，而是"指标看不懂这件事"。**
>
> **结论：整图均值类指标在"局部强调"型灯光上系统性失效。**
> 要用统计量，得改成分区/直方图/明暗分位数 —— 那是另一件事，本轮没有做。

## 对本项目意味着什么

**"模型写的结构化方案 → 画面逐项兑现"这条链，两端都有了证据**：

```
剧本 → 导演（每场预算，实测逐场零偏差）
     → 灯光（每场光影，实测逐项兑现）
     → 分镜 → 渲染
```

而且**中间每一环都是独立职位**，不是同一个提示词换了个名字。
