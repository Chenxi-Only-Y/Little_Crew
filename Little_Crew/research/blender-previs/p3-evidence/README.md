## 关键结论（按重要性）

### 1. 提示词必须写全场景 —— 这是最容易被误判成"模型坏了"的一条

只写"一位少女"时，产出是**大片暗块 + 荧光错色 + 人物数量错乱**，
看起来像 ControlNet 或底模出了问题。

补上地点与光线（"白天的山间小路 / 明亮阳光 / 蓝天白云 / 薰衣草田"）后，
立刻变成干净的画面。

> **教训**：遇到"画面崩坏"，先查提示词是否写残，再怀疑模型链路。

### 2. 控制信号用**重度模糊**，不要用实心剪影

实心剪影带内部明暗，模型会去**描摹骨架的内部细节**（手臂/腿的位置），
人物因此被驯化成骨架形 —— 就是"完全不像人"的观感。

高斯模糊（半径 ~18px @832×480）抹掉内部结构，只留
"**这一团是中景偏左的一个人，这么大**"，形状细节交还给图像模型。

见 `p3_shape_compare.png`：模糊那列在强度 1.0 下**仍然是自然的人**。

### 3. 强度 0.5 是"定位准 + 人自然"的平衡点

见 `p3_loc_compare.png`：三档强度的**构图、人物大小、位置完全一致**，
只有姿态自由度不同。所以"定位"这件事对强度不敏感，
**降强度不会损失定位，只会让人更自然**。

### 4. 灰度优于深度（与预期相反）

策划书 §3.8.8 的 U2 曾预期"白模灰度的分布可能与官方样片不同"，
暗示灰度不可用。**实测结论相反**：亮度版可用，深度版产出**无头、
手臂怪异**（见 `p3_controlnet_result.png` 的前两格）。

## 两个被推翻的自动指标（记录以免复用）

P3 过程中我写了两个"量化"指标，**两个都是错的**，且都一度给出误导性结论：

| 指标 | 它报出的结果 | 为什么错 |
|---|---|---|
| **"主体宽度" Spearman 秩相关** | ρ = -0.50（看着像"未跟随"，实际是跟随的） | 用**中位数阈值**测主体宽度，而生成图背景是**深浅不一的山林** —— 它检的是背景不是人（报出"主体宽 495px"，而图才 832px 宽） |
| **"剪影内外亮度差"** | 强度 1.0 = 33.9 最高（看着像"被锁死"，实际 1.0 反而是最跟姿态的） | 这个量测的是"剪影处与别处有没有亮度差"，与"像不像人"无关 |

> **结论：这类主体检测在复杂背景上不成立，不要复用。**
> P3 的所有判断最终都改为**直接看图**，指标只在背景干净时作辅助。
