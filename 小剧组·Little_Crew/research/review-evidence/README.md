## ⚠️ 一次夹具错误（记录以免重犯）

第一版测量报出 **50% 误杀率**。**那是夹具的错，不是门禁的错。**

我把分辨率不同的对照拼图（`p3_blur_sweep.png` 1050×230 等）
也当成"合格产物"，再喂给一条要求 832×480 的约束 ——
**门禁拦它完全正确**，因为它的规格确实不符。

> **教训**：门禁的职责是「**按声明的规格判定**」，它不该猜哪张图算合格。
> 基准由调用方给，**给错了是调用方的错**。
> 测门禁之前必须先声明显式基准，再据此筛样本。

修正后误杀率为 0%。

## 两条"反自我签收"的守卫

这两条不是普通的阈值检查，而是 C3 的核心断言：

### ① 缺观测 ≠ 通过

```
缺陷 7：观测值缺失（未测） -> RETRY ✅
```

若把"没测"当成"通过"，就等于**放行了从未被检查的约束** ——
那正是自我签收的变体，而且更隐蔽（报告上看起来一切正常）。

### ② 判定不可信 ≠ 产物不合格

```
缺陷 8：约束引用未知算子 -> ESCALATE（不是 RETRY）✅
```

三态裁定的必要性：

| 结论 | 含义 | 处置 |
|---|---|---|
| `KEEP` | 全部硬门禁通过 | 交付 |
| `RETRY` | **产物**不合格 | 带返工指令回去重做 |
| `ESCALATE` | **判定本身不可信** | 升级人工 —— **不给返工指令** |

合并后两者的后果：
· 判定不可信时也去返工 → 白烧算力，而且下次还是不可信
· 产物不合格时去叫人 → 人被迫做机器能做的事

## 已知限制（如实标注）

| 项 | 现状 |
|---|---|
| **算子系统覆盖** | 10 个，但**相似度类算子（身份/跨镜）未参与本次测量** —— 它们需要人脸模型或嵌入模型，本机没有 |
| **用假相似度报拦截率等于编数据** | 因此本次只测**确定性算子**（分辨率/大小/时长/文本） |
| L2 一致性嵌入 | **未实现** —— 跨镜漂移趋势尚无度量手段 |
| L3 跨模型族盲读 | 机制在 `agent/orchestrator.py`（已有），但**未接进门禁报告** |
| 缺陷样本量 | 8 类。足以证明"能拦"，不足以给出统计置信区间 |
