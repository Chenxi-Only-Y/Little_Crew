## 一、目标（三层，不要混淆）

### ① 交付件：**做出一集真正的成片**

不是 demo、不是片段拼贴 —— 是**能播放、有配音、有字幕、可复核**的一集。
（`outputs/_EF8/delivery/episode.mp4`：33 镜 / 202.5 秒 / 8.5 MB）

### ② 论文/答辩：一篇**诚实**的工程论文

| 要说的 | 不要说的 |
|---|---|
| 多智能体的价值在**约束与可审计** | ❌「多智能体一定比单智能体好」（我们实测**打平**） |
| 可复现：内容寻址缓存 + 种子派生 | ❌「生成了就完事」 |
| 每道闸都能量化（配额/崩脸/越权/对齐） | ❌ 靠人眼「我觉得还行」 |
| 负结果照实写（换模型无收益、口型不做…） | ❌ 只挑好看的写 |

**标题固定为《基于多智能体协作的 AIGC 漫剧生成平台》**（名称不改）。

### ③ 判据：一切结论用**可数指标**

```
覆盖率 · 配额遵守率 · 0 镜率 · 越权镜数 · 崩脸检出 · 台词覆盖率/截断句数 · 墙钟/成本
```
