多智能体协作：把「生成」变成「可判定的生成」

一页答辩 · 2026-11-12 · beta.1 · 2503 项测试 + 架构守卫 PASS · 整集真跑 16 次
主张：多智能体的价值不在「生成更全」，而在独立验证—— 在生产过程中嵌入生产者看不见自己的检查，并让结果可操作、可追溯、可交付。

表三 · 方法学结论（这部分比结论本身更重要）

发现证据对做法的约束
判分噪声 > 待测差异 同一批 58 份、同一位评审四次：差 −0.28 / −0.41 / −0.83 / −0.41 —— 方向稳定，幅度浮动 0.5 单评者只用来确认方向，不能用来调参
真正的改进都来自可数信号 2 镜场占比（A 2% / B 14%）· 场间方差（0.76 / 0.77）· 配额遵守率（6/6） 盲判只做最后确认；调参看结构统计
处置必须先有数字 真跑出现「总时长 Nones」—— audit 只给原因字符串，不给数字 缺陷记录必须带数字字段，并有回归断言
缺观测 ≠ 通过 审片明确写 notReviewed（画面质量 / 角色相似度 / 构图）；证据包同样声明边界 不能证明的事，写进产物里
