## 4.1 样板：E6 + E7 + E8 合并成一条完整论证

> 因为它们是**同一个问题的三段**（有没有用 → 用多少 → 什么时候坏事），
> 合在一起读才完整。这就是"逻辑清晰"的意思：**按问题组织，不按时间组织。**

### 问题

白模（几何预演）到底能不能约束生成画面？

### 方法（一次只变一个变量）

```
同一份 IR（提示词逐字相同、同 seed、640×384、8 步）
  ├─ 不给 apply_control      → A 组
  └─ 给   apply_control      → B 组（强度 1.0 / 0.5 / 0.35）
```

**为什么不用"跑两集对比"**：两集之间提示词会变，差异无法归因。

### 数字

| 组 | 像素变化 | 地平线行 | 盲判（花田是否主体 1-5） |
|---|---|---|---|
| A 无控制 | — | **38** | 3 |
| B `1.0` | 98.05% | 50 | **1** |
| B `0.5` | 84.68% | 25 | **4** |
| B `0.35` | 80.10% | **38** | 3 |
| B `0.35` + 加道具 | — | 38 | 3 |

### 结论（三条，含一条自我否定）

1. **控制图确实生效** —— 98% 像素变化，方向与白模几何一致，不是噪声。
2. **强度是主变量** —— `0.5`（系统默认值）在盲判下**高于无控制基线**；
   `1.0` 会把"地平线在上方"放大成主体（土坡占 2/3）。
3. 🔴 **场景道具的影响可忽略** —— 假设「空平地被模型自由发挥」**被否定**；
   土坡的来源是**提示词**（原文有"一直铺到远处的岩石"）。

### 局限（必须一起写）

- **n = 5、单镜、单人盲判** —— 只能看方向，不能下断言
- 通用像素统计**不能**当"构图听话度"指标（实测两个指标都失效）
- 该镜提示词本身把场景写成"山坡"，与"花田"意图冲突
