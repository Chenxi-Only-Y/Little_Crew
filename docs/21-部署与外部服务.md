# 部署与外部服务边界（容器 / doctor / Makefile）

> **类型**：部署说明 · **时效**：2026-11-16 · `0.4.0-rc.3` · **权威**：本文与 `Dockerfile`/`.dockerignore`/`Makefile`/`cli/doctor.py`
> **一句话**：镜像里**只有平台本体**；出图/ComfyUI/TTS/模型权重都是**外置服务，不计入平台交付物**，按环境变量指过去。

---

## 一、边界（最重要的口径）

| 类别 | 是否在镜像里 | 例子 | doctor 语义 |
|---|---|---|---|
**平台本体** | ✅ 在 | `src/`、`tools/`、Python 依赖、FFmpeg、授权目录 | **阻塞项**：缺了平台跑不起来 |
**外置服务** | ❌ 不在 | **local-gen**（本地出图 HTTP）、ComfyUI、Breeze TTS | **默认不阻塞**：挂了只影响对应路径 |
**模型权重** | ❌ 不在 | Z-Image、Wan2.2、H3… | 由外置服务/云端持有 |
**云端 API** | 不在（无状态） | Sudorelay 出图、百炼口型、DeepSeek/GLM 文本 | 按需（选了云端路径才要求 key） |
**项目配置/密钥** | ❌ 不进构建上下文 | `config/.env` | 运行时用环境变量注入 |

> **为什么这样切**：模型与服务动辄几十 GB，塞镜像既不可维护，
> 也和"本地/云端可切换"的通道设计冲突；平台本体必须能独立部署与升级。

---

## 二、构建与运行

```bash
# 构建（不含任何外置服务）
make build                 # docker build -t little-crew:rc .
# 或
docker build -t little-crew:rc .

# 运行：外置服务用环境变量指过去（Windows 宿主用 host.docker.internal）
docker run --rm -p 8787:8787 \
  -e DASHSCOPE_API_KEY=sk-... \
  -e SUDORELAY_API_KEY=... \
  -e LITTLE_CREW_IMAGE_ENDPOINT=http://host.docker.internal:8100 \
  -e BREEZE_TTS_ENDPOINT=http://host.docker.internal:8110 \
  -v %cd%/outputs:/app/outputs \
  little-crew:rc
```

- **健康检查**：容器自带 `HEALTHCHECK` 打 `/healthz`（平台本体不依赖外置服务）
- **数据卷**：`/app/outputs`（产物 + 报告页 + `.api-runs`）
- **密钥**：不要 `COPY config/`；`.dockerignore` 已排除 `config`/`.env*`

---

## 三、外置服务清单（都不计入平台）

| 服务 | 用途 | 何时需要 | 环境变量 |
|---|---|---|---|
**local-gen** | 本地出图（Z-Image） | `--render-path local` | `LITTLE_CREW_IMAGE_ENDPOINT`（默认 `http://127.0.0.1:8100`） |
ComfyUI | 可选工作流通道 | 需要白模/ControlNet 时 | `COMFYUI_ENDPOINT` |
Breeze TTS | 外部配音 | 视频模型无原生音频、且要 `--voice` | `BREEZE_TTS_ENDPOINT` |
云端出图 | Sudorelay `gpt-image-2.6` | `--render-path cloud` | `SUDORELAY_API_KEY` |
百炼口型 | `wan2.2-s2v` | `--lipsync` | `DASHSCOPE_API_KEY` |

**TTS 是兜底**：视频模型 `native_audio=True`（如 `minimax-h3`）时**不需要 TTS**；
只有需要外部配音时才设 `LITTLE_CREW_NEED_VOICE=1`，doctor 才把它当阻塞项。

---

## 四、doctor 语义（`make doctor` / `make deploy-check`）

```
平台导入 / 名册契约 / 授权目录 / 输出目录 / FFmpeg   → 阻塞项（平台本体）
local-gen / ComfyUI / TTS                            → [外置] 不阻塞，只提示
LLM key / 云端渲染 key / 模型矩阵 / 自定义供应商      → 按需或提示
```

- `make deploy-check`：JSON 输出，**阻塞项应为 0**
- 外置服务挂了：doctor 显示 `[外置] ⚠️`，但仍"可以开跑"（换成云端/改路径即可）
- 按需开关：`LITTLE_CREW_NEED_LLM=1` / `LITTLE_CREW_NEED_VOICE=1` / `LITTLE_CREW_RENDER_PATH=cloud`

---

## 五、Makefile 常用目标

| 目标 | 作用 |
|---|---|
`make doctor` | 环境自检（平台本体阻塞；外置不阻塞） |
`make deploy-check` | 同上，JSON（给 CI/部署用） |
`make build` | 构建平台镜像（不含外置服务） |
`make test` | 全量套件 + 架构守卫 |
`make serve` | 起 API（默认 8787） |
`make report WD=outputs/...` | 生成报告页（含静态流水线图） |
`make episode EP=... CREW=standard RENDER_PATH=cloud` | 跑一集（编制可选） |
