## 02 功能地图 · 系统能做什么（按层）

```
观测层   partial_report(半成品报告) · scene_check.json · script.rounds.json
              ↑ 每层都留痕
交付层   成片清单 + 证据链(内容哈希/IR哈希) + 报告页 + 导演台
              ↑
判定层   三态裁定(KEEP/RETRY/ESCALATE) · 硬规则5条 · 场景越权否决
              ↑
生成层   IR 施工单 · 编译器(能力矩阵探测) · 双通道(HTTP/图) · 内容寻址缓存
              ↑
协作层   19 职位名册 · 编排(黑板/信封) · 四族 LLM · 逐轮落盘
              ↑
资产层   角色定妆表(CHAR-ID+seed) · 白模(灰模/首帧/控制图)
```

**每层的判据**：去掉这一层，下游产物会不同吗？—— 不会，就不是一层，是装饰。

## 03 数据流地图 · 一份故事怎么变成一集

```
故事素材
   ↓ ① 剧本闭环（编剧 ↔ 剧评人，改到通过；逐轮落盘 problem+suggestion）
   ↓ ② 导演定调 → ③ 美术 → ④ 灯光
   ↓ ⑤ 分镜（shot.list）
   ↓ ⑥ 角色定妆（文字半） → ⑦ IR 桥接（每镜一张施工单）
   ↓ ╔══════════ 渲染前准备 ══════════╗
   ↓ ║ ⑧ 制片主任排期  ⑨ 白模预演    ║
   ↓ ║    → previs.mp4 / 首帧 / 控制图║
   ↓ ╚═══════════════════════════════╝
   ↓ ⑩ 出图（吃控制图；按后端分流：HTTP / 图）
   ↓ ⑪ 门禁（三态 + 硬规则 + 场景越权）→ RETRY 回 ⑩
   ↓ ⑫ 成片清单 + 证据链
   ↓ ⑬ 视频合成（静帧+KenBurns ／ H3 真片段）
成片 mp4

三条并行工程流（横向穿所有层）
  A 缓存流   IR+配置 → cache key → 命中则跳过（74s → 0.6s）
  B 证据流   每镜 内容哈希 + IR 哈希 + 提示词 → delivery.evidence.json
  C 判定流   裁定 → 原因文本 → 退回/升级/放行 → 记录
```

## 用法（纪律）

| 场景 | 该查哪张 |
|---|---|
| 加一个入口 / 暴露服务 | **01 门户图** —— 门户只有四类，新增要能说清为什么 |
| 加一个模块 / 一个职位 | **02 功能地图** —— 它属于哪层？判据成立吗？ |
| 改链路顺序 / 加阶段 | **03 数据流地图** —— 位置错了就会"静默少做一件事"（今天 5 次） |
| 技术决策看起来合理但奇怪 | **回到三张图** —— 对不上就重审决策，别改图 |
