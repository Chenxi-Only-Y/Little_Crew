## 文档写作三条纪律

1 **CHANGELOG 不改历史** —— 历史是记录，不是配置
2 **过时内容不删，加前向指针** —— 读者需要知道"走过哪条弯路"
3 **不利数据照实写** —— 换模型无收益、多智能体打平、口型不做，都留在正文里

## 文档格式规范（2026-11-10 起，全部统一）

每份 `.md` 必须遵守：

| 项 | 规则 |
|---|---|
| **唯一 H1** | 全文只有一个 `#`；子节从 `##` 起（代码块里的 `#` 不算） |
| **标题不带日期** | 日期/版本放在头的 `**时效**` 行，标题只写主题 |
| **头四行** | `类型` / `时效` / `权威` / `一句话` —— 缺一行就算不合规 |
| **类型取值** | `主文档` · `状态页` · `索引` · `附录` （四选一） |
| **权威取值** | `✅ 唯一权威` · `✅ 权威（仅索引）` · `部分（状态以 docs/16 为准）` · `⚠️ 历史，可能过期` |
| **过时不删** | 加前向指针（"已过期，见 X"），不抹掉历史 |
| **数字带出处** | 任何指标后面写 `§节号` 或 `alpha.NNN` |
