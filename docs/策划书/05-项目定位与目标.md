## 二、项目定位与目标

### 2.1 一句话定位

> 以「**语义级节点编排 → 自动编译为 ComfyUI 执行图 → 确定性验收 → 回写共享黑板**」
> 闭环为核心的漫剧工业化生产平台。

### 2.2 两个并列的核心

本项目有**两个**核心，它们构成一个闭环的两端，**不是主从关系**：

```
   ┌──────────────────────────────────────────────┐
   │  多智能体协作                                  │
   │  回答：谁来决定、谁来质疑、谁裁决               │
   └───────────────────┬──────────────────────────┘
                       │ ① Agent 写 IR（分工产出语义图 + 约束）
                       ▼
   ┌──────────────────────────────────────────────┐
   │  统一 IR（Unified IR）                        │
   │  回答：决定以什么形式存在、如何被验证、如何被执行  │
   └───────────────────┬──────────────────────────┘
                       │ ② 编译 → 执行 → 产出
                       ▼
   ┌──────────────────────────────────────────────┐
   │  ComfyUI 执行底座                             │
   └───────────────────┬──────────────────────────┘
                       │ ③ 产物 + 降级原因 + 断言结果 → 回写黑板
                       └──────────► 回到多智能体协作
```

**为什么二者不可分割**：

- **没有 IR**，多智能体协作只能产出**散文**——一堆积木式拼接的提示词，
  无法校验、无法缓存、无法验收。
- **没有多智能体协作**，IR 只是一个**空壳表示**——没人往里写，
  也没有多视角的质疑机制。

### 2.3 三个可量化目标

| # | 目标 | 度量 |
|---|---|---|
| **G1** | 打通端到端出片 | 从一句剧本到一集 60 镜成片，**全自动无人工干预** |
| **G2** | 证明成本可控 | 改一句 IR，**只重跑受影响的镜头**，其余命中缓存；给出实测节省比例 |
| **G3** | 证明验收有效 | 跨模型族盲读门禁能**拦住**人工判定为不合格的产出，给出拦截率 |
