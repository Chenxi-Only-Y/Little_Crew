## 七、与竞品的边界

> **这一章回答一个问题：既然平台都能生成，为什么还要多这一层？**
> 答案不是「我们生成得更好」，而是「我们管的是另一件事」。

### 7.1 平台按「能不能进我们的流水线」分三类

**A 类 · 有公开 API，可当后端**

| 平台 | API 入口 | 参考视频 | 多图参考 | 备注 |
|---|---|---|---|---|
| **即梦 Seedance** | [火山引擎·即梦计费](https://docs.volcengine.com/docs/JimengAI/JimengAI-VideoGenerationBillingInstructions) | ✅ | ✅ | **参考生视频 + 多图锁角色**，最强 |
| **可灵 Kling** | [百炼 kling-v3-omni](https://github.com/modelstudioai/skills/blob/11f8ebc6db65725a6389665ac8a2277b2fbcbb32/skills/bailian-docs-llm-wiki/raw/model-user-guide/support/model-studio-model-list/model-list-video-generation/kling-v3-omni-video-generation.md) · [定价](https://www.cloudzero.com/blog/kling-ai-pricing/) | ⚠️ | ⚠️ | v3-omni 支持分镜 |
| **Vidu** | [官方定价](https://platform.vidu.com/docs/overview/pricing) | ⚠️ | ⚠️ | **单价最低** |
| **万相 3.0** | [官方 API](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference) | ⚠️ | ⚠️ | 阿里系 |
| **MiniMax 海螺** | 已有（规格进 `video_ref.py`） | ✅ | ⚠️ | 2~15s、≤50MB |
| **Runway / Veo / Luma / Pika** | 均有 | 部分 | 少 | 合规与成本是主要问题 |

**⚠️ 的含义**：有链接但**没有逐条读到官方规格**。接一家前必须把规格抄进 `LIMITS` 并跑通一次真调用。

**B 类 · 只能当素材源**：Midjourney（无官方 API）· Kling Motion Control（要求 realistic style character，白模不适配）· Runway Act-Two

**C 类 · 是竞品，只能当对标**：**LibTV**（已查：无公开 API；白模 + Blender 插件 + 3D 导演台全产品化）· **万镜一刻**（阿里云全链路 AIGC 视频创作平台）· 即梦/可灵网页版

### 7.2 两个必须正视的事实

1. **Sora 已关停** —— 2026 年的选型文章已在讨论[「Sora 关停后的替代」](https://www.layer3labs.io/comparisons/sora-alternatives)。
   任何"Sora 可用"的旧认知作废。
2. **「一键漫剧」已经是成型品类** —— [AI 视频画布横评](https://www.163.com/dy/article/L9ACC1ES051284V8.html)里，
   影视出片 / 一键漫剧 / 电商已经分化。

> **所以「把漫剧生成出来」不再是任何人的差异化。**
> 我们的位置只能是：**谁决定、谁判定、谁退回、怎么证明**。

### 7.3 与 ComfyUI 的关系：**我们是消费者，不是替代者**

| 层 | 谁 |
|---|---|
| 要什么（意图 / 约束） | **我们** |
| 谁来做（19 个职位协作） | **我们** |
| 算出来（采样 / 节点） | **ComfyUI** |
| 算得对不对 | **我们** |
| 不对怎么办（退回给谁） | **我们** |
| 怎么证明查过 | **我们** |

**判据**：**ComfyUI 有的能力 → 消费它；ComfyUI 没有的能力 → 我们做。**
所以：不自研图编辑器、不自研推理补齐控制/参考能力（见 §八 8.6）。

### 7.4 先接哪三家（覆盖三种能力）

| 能力 | 选谁 | 理由 |
|---|---|---|
| **参考视频（白模命门）** | **Seedance** | 唯一确认「参考视频 + 多图锁角色」双能力 |
| **便宜跑 A/B** | **Vidu** | 单价决定 A/B 跑不跑得起 |
| **图像（6 张定妆图）** | Flux / 即梦 | 要便宜、要稳定 |

**纪律：不许「都接」。**
论文要的是「同一份 IR 在不同后端上结果可比」，不是「我接了 8 家」。
接 3 家做一张四方对比表（Seedance / Vidu / 本地 H3 / ComfyUI），比接 8 家各跑一次强得多。
