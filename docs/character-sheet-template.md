# 角色设定表提示词模板（固定格式 · 定稿）

> 用户 2026-10-07 拍板：**左侧正脸放大 ≈1/3，右侧并排 正面/侧面/背面 三视图**，16:9 横幅。
> **路线：16:9 单图（一致性优先，接受配饰丢）。**
>
> 代码常量见 `app/agents/stage2/character_sheet_template.py`，
> 测试见 `tests/test_character_sheet_template.py` 与
> `tests/test_character_sheets_integration.py`。
> **已接进流程**：开关 `character_sheet_enabled`（默认开），
> 产出落在 `state["character_sheets"]`。

## 一、版式（不许改）

```
┌──────────────┬─────────┬─────────┬─────────┐
│              │         │         │         │
│  正脸放大     │  正面   │  侧面   │  背面   │
│  （≈1/3 宽）  │  全身   │  全身   │  全身   │
│              │         │         │         │
└──────────────┴─────────┴─────────┴─────────┘
                   16 : 9
```

**四条硬约束**（漏一条就出不来）：

1. **同一角色、同一套发型和服装** —— 不写这句，四个视角会变成**四个人**
2. **站姿自然、双手自然下垂** —— 不写则每格姿势乱、不像设定图
3. **发夹/配饰位置逐视角保持一致** —— 不写则发夹只在一个视角出现
4. **浅灰偏白影棚背景 + 柔和自然阴影 + 大量留白** —— 保证底色统一

## 二、固定模板正文

```text
生成一张角色设定图（character design sheet），横幅 16:9 构图。
画面布局：左侧是一张占画面约三分之一的大尺寸面部特写，
右侧并排站立同一个角色的正面全身、侧面全身、背面全身三个视图。
三个视图必须是完全同一个角色、同一套发型和服装，
站姿自然，双手自然下垂。
角色：{name}。{appearance}
{style}
整体为精致 3D 渲染质感，柔和影棚光，浅灰偏白背景，
柔和自然阴影，8K，精细发丝与材质，画面干净克制、大量留白。
```

**占位符只有 3 个**：

| 占位符 | 内容 | 谁来填 |
|---|---|---|
| `{name}` | 角色名 | 系统（大纲/剧本） |
| `{appearance}` | 见第三节六段结构 | LLM 按大纲生成，或用户直接给 |
| `{style}` | 风格/镜头段 | 默认见下，可整体替换 |

**`{style}` 默认值**（与角色无关，可复用）：

```text
85mm 人像镜头，柔和珍珠质感轮廓光，高级时尚大片质感。
```

## 三、`{appearance}` 的六段结构（颗粒度基准）

**每段都要具体到能画出来。** 含糊的形容词（"很漂亮""有气质"）模型只会**平均化**，
四个视角就全不一样了。

### 1. 气质基调
> 一位年轻的东方女性，气质清冷、柔美、精致，带一点轻甜酷和梦幻少女感。

### 2. 面部（逐部位）
> 皮肤白皙细腻，呈柔和哑光质感，干净无暇。鹅蛋脸轮廓精致，深黑色纤细长眉，
> 眉尾轻微上扬，狭长的灰蓝色眼睛微微上挑，眼神清冷柔和，卧蚕饱满，睫毛纤长，
> 眼妆是低饱和灰棕色带淡粉玫瑰红晕，下眼睑有轻微的哭红感。鼻子窄直高挺，
> 鼻头小巧，嘴唇是水润的玫瑰豆沙色，唇形饱满，微微微张。

**顺序**：肤色 → 脸型 → 眉 → 眼（形状/颜色/神态/卧蚕/睫毛/眼妆/下眼睑）→ 鼻 → 唇。
**要颜色词与形状词**，别堆形容词。

### 3. 发型
> 黑色长卷发，长度及腰，发量浓密，发丝呈自然的大波浪卷，带丝绸光泽。
> 前额有轻薄的空气碎刘海，两侧垂落几缕修饰脸型的发丝。
> 两侧头发各别一枚粉色水晶蝴蝶发夹。**三个视角中的发型、刘海和发夹位置保持一致。**

**顺序**：颜色 → 长度 → 发量 → 卷度 → 光泽 → 刘海 → 侧发 → 发饰，
末尾**显式要求逐视角一致**。

### 4. 服装（分上下身）
> 穿甜酷 Y2K 少女时装：柔和草莓粉色修身吊带短上衣，方形领口有白色蕾丝滚边，
> 胸前有小型缎面蝴蝶结和纵向细带装饰；外罩一件半透明珍珠白蕾丝薄纱长袖短外套，
> 袖口宽松呈喇叭状；下身是雾灰色高腰层叠百褶迷你裙，两到三层不规则裙片，
> 下层露出少量粉色内衬，裙边有细窄蕾丝、小蝴蝶结和银色珠链吊坠装饰，
> 腰部有纤细银色腰链。

**每件单品写清**：品类 + 颜色 + 材质 + 版型 + 装饰细节。

### 5. 配饰（逐个列）
> 粉色水晶蝴蝶吊坠耳环配银色长流苏，脖子上叠戴两条细项链
> （一条银色项链配粉色水晶吊坠，一条细小珍珠链），一只柔粉色小巧肩包，
> 包上有银色金属扣和粉色吊坠。腿上穿白色半透明蕾丝及膝袜，袜口有蝴蝶结；
> 脚穿粉白配色厚底运动鞋，鞋面有粉色蝴蝶结和银色扣件。

**顺序**：耳 → 颈 → 包 → 袜 → 鞋。
**材质与颜色必须成对出现**（"银色金属扣""粉色水晶"），否则模型自由发挥。

### 6. 身形
> 身材高挑，九头身时装模特比例。

## 四、负面提示词（固定）

```text
multiple panels beyond the layout, duplicated character, inconsistent face,
different person, mismatched outfit, text, letters, words, chinese characters,
watermark, signature, logo, caption, annotation, arrows, grid lines,
border, frame, thin border, black frame, picture frame, vignette, divider,
extra limbs, extra fingers, deformed hands, bad anatomy,
blurry, lowres, jpeg artifacts
```

**三组各有用途，都不能删**：

| 组 | 防什么 |
|---|---|
| `text / letters / words / chinese characters / watermark / caption / annotation` | **乱码**。模型写不对中文，漏这组就往图上写标注 |
| `duplicated character / inconsistent face / different person / mismatched outfit` | **四个视角变成四个人** |
| `grid lines` | 版式靠提示词说，别让模型自己画分隔线 |
| `border / frame / black frame / vignette / divider` | **边缘细黑框**（高分辨率下才显形） |

## 四·五、⚠️ 风格必须**单一、无矛盾**（用户问过"为什么风格不一致"）

### 归因实验

**实验一**：同一 seed、同一角色描述，**只换风格段** → 风格**跟着风格段变**。
**实验二**：同一提示词、**只换 seed**（4 张）→ 风格**完全稳定**
（脸型/毛孔质感/发丝/服装全一致），seed 只影响人物细节。

**结论：风格漂移的主因是"每次换了风格词"，不是模型随机性。**

### 旧默认值自相矛盾（实测踩过）

```text
"3D 写实"                        ← 要写实
"85mm 人像镜头 / 8K / 大片质感"    ← 摄影词 → 拉向真人照片
"类似 BJD 人偶的精致五官"          ← BJD 是**塑料娃娃**
→ 三个方向互相拉扯 → 模型每次随机挑一个
```

三版对照结果（同 seed 同角色描述）：

| 版本 | 风格段 | 结果 |
|---|---|---|
| A 旧默认 | 3D写实 + 85mm + BJD | ❌ 塑料感、腿被拉长 |
| **B 纯 CG** | UE5 + 次表面散射 | ✅ **皮肤通透、比例正常** |
| C 单锚点 | 只有一句 | 与 B 接近 |

### 现在锁定的风格（三段同一套词，无摄影词）

| 段 | 内容 |
|---|---|
| `{style_prefix}` | `半写实 3D CG 风格的` |
| `{style}` | `虚幻引擎 5 渲染，次表面散射皮肤，柔和均匀的棚拍灯光。` |
| `{render_tail}` | `整体为半写实 3D CG 游戏角色渲染，皮肤通透有真实感、保留次表面散射的通透质地，五官比例写实但保留动漫化的精致感，浅灰偏白影棚背景，柔和自然阴影，4K，精细发丝与布料材质，画面干净、大量留白。` |

**两条规矩**（有测试守着，见 `tests/test_character_sheet_style.py`）：

1. **不许跨方向混用** —— CG 词 / 摄影词 / 塑料娃娃词三组互斥，只能选一组。
2. **不许在三段里重复风格名** —— 重复会过度加权。`{style_prefix}` 刻意
   不带"角色"二字，否则会拼成"游戏角色**角色**设定图"。

**改风格要整体替换三段，别混着加。**

## 五、实跑验证（2026-10-07）

```
尺寸 1216×688（16:9）   耗时 29~42 秒
```

结果：左侧正脸放大 ≈1/3、右侧 正/侧/背 三视图、同一人同服装、
发夹位置一致、**零乱码文字**。

**侧脸要点**：只写 `side view, profile` 会**退化成 3/4 角**。
要补侧脸专有特征才稳定 —— 实测有效的是
`full profile` + `body turned 90 degrees` + `only one eye visible` + `side silhouette`。

## 六、⚠️ 两条路的选择（**5 次对照试验**的结论）

| 方案 | 全身 | 配饰 | 一致性 |
|---|---|---|---|
| 16:9 单图（v1 约束少） | ❌ 截大腿 | ✅ 有 | ✅ |
| 16:9 单图（v2 加全身约束） | ✅ | ❌ 丢 | ✅ |
| 16:9 单图（v3 缩脸栏 + 配饰清单） | ✅ | ❌ 丢光（连灰裙都没了） | ✅ |
| 混合（16:9 → 切片 → 放大） | ✅ | ❌ **还是丢** | ✅ |
| **4 格独立 → 拼接** | ✅ | ✅ **全保住** | ❌ **脸会漂** |

**根本矛盾**（这是容量的物理限制，不是提示词能修的）：

```
16:9 一张图 = 要同时画「1 张大脸 + 3 套精细服装」
            → 容量不够 → 模型随机丢东西（丢哪件不可控）

4 格独立     = 每格只画「1 个视角 + 1 套服装」
            → 容量够 → 配饰全在
            → 但各格独立采样 → 脸漂
```

**「切片放大」救不了**：切片只是**裁开**已经画好的图 —— 那张图里**根本没画的
东西**切不出来。信息在生成那一刻就丢了，后期处理补不回来。

**用户 2026-10-07 选了「要一致性，接受配饰丢」**，所以定稿走 **16:9 单图**。

实测：Y2K 少女的"灰百褶裙粉内衬 / 银色珠链 / 蕾丝及膝袜 / 粉白厚底鞋"
在 16:9 单图里常被简化掉（甚至整条裙子变成粉色连衣裙），
但**四个视角永远是同一个人**。

### 拼接那条路没删，留着

`app/services/character_sheet.py` 的 `compose_character_sheet()` 与
`slice_sheet_panels()` 都保留（各 8 条 + 测试）。将来若做"概念设计稿"
（重点是服装/道具对不对，一致性次要），直接用它。

### 为什么设定表**不能**当 IP-Adapter 参考图

CLIP 把整图编成**一个**向量，没有"分区"概念 —— 4 个视角的特征会**混在一起**：

```
1920×1080 的设定表
├── 左脸特写 ~652×1088  → 缩放后
└── 三个全身 各 ~422×1088 → 每个缩到约 78×224
```

拿这个混合向量去生"角色站在雨夜街头的全身镜头"，模型收到的是
「一张超大的脸，旁边还有三份同样的人」→ 常见结果：**画面被脸占据**、
**生成多个副本**、**角度串味**。

**所以流程里两者分开**：

```
character_sheets            ← 16:9 设定表，给人看（展示层）
character_reference_images  ← 逐视角独立图，给 IP-Adapter（锚定用）
```

有测试守着这条（`test_downstream_reference_is_still_the_per_view_image`）。
